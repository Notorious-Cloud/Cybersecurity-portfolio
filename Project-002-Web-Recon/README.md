## 🎯 Objective

The objective of this project is to perform reconnaissance and enumeration
against a deliberately vulnerable web application hosted within my isolated
VirtualBox penetration testing laboratory.

The project focuses on identifying:

- Open ports and services
- Web server information
- HTTP technologies
- HTTP response headers
- Directories and files
- Potential areas of the application's attack surface

No exploitation will be performed during the initial reconnaissance phase.

## 🔬 Methodology

The assessment will follow this process:

1. Confirm target availability
2. Perform network reconnaissance
3. Enumerate HTTP services
4. Identify web technologies
5. Inspect HTTP headers
6. Discover directories and files
7. Map the application's attack surface
8. Document findings and evidence
